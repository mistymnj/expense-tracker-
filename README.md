💰 Python Expense Tracker

📌 About the Project

The Expense Tracker is a beginner-friendly Python project designed to help users record and track their expenses. It provides a simple way to manage daily spending and calculate total expenses.

✨ Features

- Add new expenses with a name and amount.
- View all recorded expenses.
- Calculate total expenses.
- Display expense details in a simple format.

🛠️ Technologies Used

- Python
- Lists and Dictionaries
- Functions
- Conditional Statements
- User Input and Output

🎯 Objective

To practice Python programming concepts by building a practical application for tracking personal expenses.

🚀 Learning Outcome

This project helped me improve my understanding of Python functions, data structures, user input, and basic program logic.
